# Ajaykumar MST — Portfolio

A personal engineering portfolio built as a lightweight, responsive static website. It presents my work in systems engineering, model-based systems engineering (MBSE), simulation, digital twins, and aerospace applications.

## Portfolio

The site includes:

- Professional profile and technical focus
- Selected engineering projects and case studies
- Professional experience at Boeing India and Modelon Engineering
- Publications and conference presentations
- Technical expertise, education, and contact links

## Built with

- HTML5
- CSS3

The site uses embedded CSS and has no package installation or build step.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Open this repository on GitHub and select **Settings**.
2. Open **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. After GitHub Pages finishes deploying, use the site URL shown in the Pages settings.

The expected project-site URL is <https://ajaymst.github.io/My_Portfolio/> once Pages is enabled for this repository.
